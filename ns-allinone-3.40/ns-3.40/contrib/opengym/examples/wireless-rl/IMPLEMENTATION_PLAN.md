## 2. 每步统一交付与用户验收

一次只推进当前子步骤。实现、最短相关检查、证据整理、文档同步、Git 提交推送完成后，
向用户说明功能、失败/限制、原件位置与冻结提交，状态更新为“待用户验收”。用户明确
确认后才能将其记为“已验收”并进入下一步；代码完成或 agent 自评 PASS 不等于用户验收。

每步提供：

1. 该步需求、接口和排除项；当前源码事实与拟实现功能分开。
2. 最小有意义的单元/协议检查和相应原生闭环；组件 PASS 不当作整任务完成。
3. 一次推送冻结下的完整预声明矩阵，失败、中断和所有重试保留。
4. 完整命令、代码/模型哈希、scene/seed/参数、输出与结论，追加共享 [log.md](log.md)。
5. 受影响的指南和 [ROS 启动命令](../../../../../../ros2_ws/ros2-multi-robot-automap/launch_commands.md) 同步。

修改门限、reward、输入/动作或实现后，新建版本和结果，不混用旧 PASS。
优先修复一般性根因，不能按某个场景/seed 叠加规则。文档整理不要求重跑仿真。

报告适用范围。旧路线原件通过 Git 对象/备份分支和归档索引可恢复，不删除失败证据。

出口：所有活动入口一致描述固定三机器人、“先导航 RL、后冻结策略接网”；运行命令
仍是当前可执行的传统基线；无虚构训练/gateway CLI；相对链接、代码事实和证据索引
通过静态检查；源码、配置、权重和实验原件未变；提交并推送。等待用户审阅路线。

### MR3-P1A：三机器人任务与 95% 测量契约

- 将新研究的默认运行/检查固定为 tb1/tb2/tb3；不新增其他数量实验。清理活动默认值和
  遗留入口依赖前先审计，不在本轮文档里假称已经删除非三配置。
- 审计 SDF 真值、室内 ROI、激光高度、frame、窄缝/封闭格、mesh 与重采样边界。
  冻结任务 ROI、95% 正确自由分母、地图质量门限、三台有效参与和接触/监测口径。
- legacy schema3“每台碰撞 topic 曾收到一条”不代表整个任务持续监测，且仅覆盖
  `base_collision`；P1A已增加18路源龄/接收龄与中断锁存，验证轮、脚轮、雷达等全机体的非支撑
  接触监测，预声明正常轮/脚轮—地面支撑接触的排除规则。真实碰撞不能漏记，保留
  接触几何、真实机体、截止优先和不可覆盖原件。
- 用开发场景建立 95% 可测、可达的诊断与传统基线，保留新/旧测量对照；不得按失败格
  裁剪分母或把 90% 当新成功。对不支持的区域先修真值或场景并预声明。
- 冻结 T_max（已固定 300 仿真秒）、地图质量门限、任务起点/预热、数据划分、后续矩阵
  与训练预算计算方法；声明测试暴露后的确认集预留或重新生成规则。任务时间从统一
  放行开始，不掺 ROS 启动墙钟。

出口：三机器人完整原生任务证据，95% 口径可解释且可达；ROI/场景/参数/schema 哈希和
真值隔离审计；预声明开发、验证与未见布局测试清单。指标契约有未决项不能进入训练。
本步不产生 RL 或通信性能信用；历史两图 seed101 不作为新多种子矩阵。

### MR3-P1B：稳定目标、观测与所有权适配（2026-10-15已验收）

- 提供策略观测快照、候选/掩码、稳定目标 dispatcher 和传输抽象的理想实现。
  状态/地图/回执自此用 source stamp、episode epoch、序号和版本，预留年龄/缺失字段。
- 定义实际消息内容、发送频率、地图编码/增量语义、队列/重试与租约；P1C验证吞吐后
  在训练前锁定，接网时不能改变这些条件。完整字节实现可在P3A补齐并验等价。
- 当前接口为 K=8+KEEP/WAIT 的联合离散目标、名义1秒快照、5秒承诺；本步验证适配可用性，
  不证明95%任务成功。P1B rooms异步2/3秒间隔保留原范围；固定dt与吞吐由P1C独立stepped证据提供，训练前锁定。
  几何候选代表性、合法等待与实际可行性仍须验证后才锁定；本步提供确定性几何/掩码及三台
  实际导航证据，保守交集限制见报告，尚未证明95%任务的候选充分性，不能用短探针替代该验证。
- 从 `control.py` 中隔离导航协议能力；RL 与旧手工目标分配不能同时拥有 action client。
  禁止坏点重派/效用 argmax 兜底；旧控制器可在单独 baseline 模式运行。
- 训练前定义机器人端本机地图+交付共享图副本的规则，以及已交付队友状态的安全契约，
  对理想模式验证，为接网保持执行条件一致。不能留到模型冻结后才决定 Nav2 信息来源。
- 用可追溯脚本策略验证导航（它是适配测试，不是 RL），检查保持不重发、最短承诺、
  接受/取消终态、拒绝、目标过期、未知所有权、episode 迟到与安全停止。

出口：固定三机器人适配闭环、确定性观测/候选/replay、无目标抖动、单一所有权；
协议失败有明确终态和原件；观测无真值。预定网络边界的理想版本与原基线差异有解释。

### MR3-P1C：训练环境与采样工程（2026-10-16已验收）

当前实现以1000个1ms物理tick完成1秒策略步，每20 tick检查真实50Hz clock相位、交付水位和终态；
seq0将首次正确格账绑定首快照地图。完整进程reset、外部截断的真实取消/闭合及终态ACK均有源码，
W7独立验证重复reset/采样、最后短步/零尾步与关闭门禁；GPU保留原接口probe范围。
不把单元检查、P1B或v6矩阵代替本次证据；用户于2026-10-16验收完整结果。

- 实现 Gymnasium reset/step 接口、有限任务终止与外部截断区分、奖励独立进程和首次
  正确格账；测试重复地图/回环/安全介入不能刷分。
- 系统 ROS 与 conda 学习端用明确 IPC 分离，不污染环境。完整 reset 清理传感/SLAM/
  Nav2、地图缓存、目标所有权、时间 epoch、历史与 reward 账。
- 同场景 seed reset 可重复；跨 seed 不复用旧地图/目标；崩溃、失联与超时分类有据。
- 测量 1/2/4 worker（每 worker 三台）的启动/reset/transition 吞吐、仿真倍率及 CPU/GPU
  占用；选择可持续并发数与隔离端口/域。长训练必须先证明不会累计僵尸进程/显存/日志。
- 对齐固定步长与实际 dt；明确最后一个短步及剩余时间；不用未经修改的变时长 PPO。

出口：稳定多 episode 原生采样、reset 和失败隔离证据；reward/action/obs schema；
可复现最小 GPU forward/backward；实测预算。只有确有采样瓶颈时才提交快速二维预训练
的独立方案给用户验收，不直接替换 Gazebo 正式环境。

### MR3-P2A：联合 PPO 最小闭环（2026-10-16已授权，未完成/停止）

使用成熟的 MaskablePPO 与自定义地图/状态编码，前馈联合 actor、集中式 critic。
掩码保存在 rollout 中；评估使用 mask-aware 接口；训练日志包括熵、KL、价值误差、
覆盖、时间、失败、目标切换、安全介入，而不只画 reward。

P2A v6沿用v3候选/导航、v4日志/审计和v5未折扣目标，已补评价器逐量子消费相位；
每台运动/目标仍由策略选择，不增加手工兜底，不放宽95%/300秒、参与或机体安全门禁。
[各版原件、失败与诊断](report/20261016_mr3_p2a.md)和旧计划保留；v5/v6自动基础设施停止与原完整审计FAIL保留；v6工程链PASS不覆盖pilot infra或提供P2A完成信用。

先验证固定开发布局能学习有效分工，随后加入预声明开发布局/姿态变化；不使用留出
测试挑参数。每个训练 run 记录 seed、预算和模型版本，阶段性结果明确是 pilot。

出口：真正由网络选目标的三机器人 Gazebo episode，无手工目标兜底、无真值输入；
能达到已冻结 95% 任务而不是单纯机器人运动；至少一条完整可复现训练/验证链。
单种子 pilot 不宣称统计优于基线。验证未达标先诊断表示、采样、候选与 reward，不接网。

### MR3-P2B：同接口比较与主模型选择

首轮必须包含传统前沿基线、同候选几何基线、联合 PPO 和同离散动作 DQN/Double DQN。
DQN 复用框架/经验但不能加载 toy 15维/5动作 checkpoint；记录 replay 候选和下一状态掩码。
公平固定任务、导航/安全、动作周期、候选、主要编码容量、采样与调参预算，报告样本及
墙钟效率，至少三条独立训练种子，若可承受则五条。

连续局部子目标的 SAC/TD3 仅在离散候选限制或离线样本效率诊断支持时增加；这比较完整
方法，不能说只换算法。无需机械地跑 DDPG/PPO/DQN/SAC/TD3 全部组合，也不新增分散 MARL。

出口：验证集上的失败计入比较、置信区间与选型理由；没有显著胜出时明确说明；选模型
及确定性推理模式，正式布局/种子与网络条件仍未用来调参。

### MR3-P2C：理想通信验收与冻结

用统一冻结源码完成完整三机器人正式矩阵。建议起始规模：至少三种未见布局，每布局
十个任务 seed，并跨至少三条训练 seed 评估；确切预算先于测试预声明。
布局/姿态/传感器随机性分别记录；历史已有布局不是未见布局。

出口：95% 主任务成功率至少 90%，正式验收矩阵零真实接触，持续安全监测与导航所有权
有效，三台真实参与；所有失败保留。更快的主张使用含失败的时间指标和配对区间。
未达到成功率/安全门禁不接网，修复后新冻结重跑，不能筛掉失败模型/episode。
若修复依据正式测试反馈并影响任务结果，已暴露布局/任务种子转为开发/回归集；
原矩阵重跑只作修复回归，独立泛化验收另用预声明且未暴露的布局与任务种子。
无新留出则仅提供回归结论，不宣称 P2C 未见布局门禁通过，不以换 seed 掩盖已见布局。
纯基础设施无效测量仅可按预声明规则原样重试并留原件，策略诱发的失败不适用。
冻结权重、归一化、观测/候选/掩码、时间、Nav2/SLAM/安全/地图规则和模型选择依据。
从此到 P5 策略只读；不在线更新、重新选模型或针对网络调导航参数。

### MR3-P3A：真实信息边界与双向 gateway

将 P1B 的理想传输抽象扩展为后端 received store、三台 robot edge、导航 action proxy、
完整字节序列化、源时间/版本/id/租约与交付审计；先用理想直通，不启动 ns-3。

覆盖状态/地图/回执上行及目标/取消/共享图/队友状态下行。Nav2 不再直接读后端实时
`/merge_map`，peer 避障不再订阅 raw 全体 odom/TF；后端不直接访问机器人 action Future。
传输速率、压缩/增量、队列/重试/安全策略需在训练前的契约基础上验证并冻结。

出口：拓扑/订阅白名单、完整字节与版本账；上下行分别全丢时，raw ROS 继续发布也不能
刷新远端缓存或执行新命令；缓存状态只随交付改变。直通与 P2C 理想实现等价（允许的
异步误差预声明）。不等价则回到受影响早期步骤重新验收，不能偷偷重训后称模型未变。

### MR3-P3B：受控通信故障验证

按确定性消息夹具验证延迟、drop、乱序、重复、地图缺片/缺基版、ACK 丢失、迟到取消、
过期目标、跨 epoch 及 outage/recovery；记录信息龄、租约和唯一执行次数。
分别验证上行状态、地图、下行目标、回执和共享地图，检查预期暂停/恢复与错误所有权。
不能用实时队友信息补洞；预先声明网络陈旧处理，真实安全和导航错误仍需保留。

出口：每个故障的交付→缓存→决策/执行因果链、无旁路及无重复目标；模型哈希不变；
三机器人短闭环。这是协议验证，不是 Wi-Fi/任务统计性能信用。

### MR3-P4A：ns-3.40 Wi-Fi 分组模型

实现 1 AP+3 STA，实际应用序列化 payload 进入 socket/IP/MAC/PHY。
先做独立已知负载的网络组件测试，验证分片重组、实收字节、校验、队列、时延/丢失、
重传与 pcap/trace 对账；禁止虚拟用户调度或只送 id 后读取未传输最新对象。

初始候选 802.11n/20MHz，确定 Yans/Spectrum、MCS/功率/传播/墙损耗假设；冻结 AP
位置、场景移动映射和健康/距离遮挡/竞争负载条件。没有观测瓶颈时如实报告，不临时
加填充流量或人为干扰制造退化。无线位置真值只能给传播模型。

出口：真实 Wi-Fi 组件与原件 trace，字节/时延可解释、三 STA 正确归属；payload 通过
实际接收恢复，无应用旁路。本步独立网络测试不计 ROS 任务闭环完成。

### MR3-P4B：因果时钟与最小联合闭环

先验证仿真时间协议，再运行任务：统一 epoch；ROS/Gazebo 与 ns-3 时间推进屏障；
传感源、应用生成、网络交付与执行时间没有负龄或未来数据；任务时间不混墙钟。
优先实验物理多步/网络事件分段锁步，20ms 起始量子，并做 10/20/50ms 敏感性和重复性
检查；验证 ROS 异步回调水位/顺序，记录额外量子延迟，不能假定 `pause/unpause` 足够。

冻结最终推进器、屏障、回调水位、同刻次序和量子；以只读模型在最终时钟下复验
理想接口/gateway 直通等价，以及最终理想模式与 P2C 理想任务等价，比较矩阵/误差界限
须预声明。P3A 的旧时钟检查不能替代；不等价返回受影响步骤验收，不归因于 Wi-Fi。

出口：单消息与移动节点因果夹具、断链证据、时间误差预算及量子收敛；同冻结模型的
三机器人健康 Wi-Fi 最小任务闭环，全部结束/失败进程有界退出。
RealtimeSimulatorImpl 仅对齐机器墙钟，若使用它必须独立证明时基可用；未验证耦合只算
演示。此门禁失败时停留本步，不发布网络任务比较。

### MR3-P5：冻结策略的网络影响与路线终点

按预声明的同场景/任务 seed 配对比较理想接口、gateway 直通、受控故障、健康 Wi-Fi、
受限 Wi-Fi；网络 seed 独立重复，模型/归一化/导航参数只读。
所有分支共用 P4B 最终调度器、屏障和量子，理想交付也走相同钩子；重新运行配对
理想基准，不直接复用 P2C 旧时钟结果。量子/调度敏感性单列。

输出完成率、含失败时间、T95 分布、C_hub/C_physical、地图质量、接触、路径和安全停止，
联合 AoI/时延/丢片/重传/目标执行龄/时钟误差解释。保留原始 episode、失败和配对区间；
不能把同模型很多任务 seed 当作独立训练 seed，也不混不同冻结版本拼矩阵。

出口：可复现双向 Wi-Fi 联合闭环、完整统计与因果限制报告，结论允许无显著退化。
提交推送后给用户验收。**本路线到此停止**；网络影响的解决方案、通信学习和实机部署
等待用户下一轮研究指示，不自行追加 P6/P7。
