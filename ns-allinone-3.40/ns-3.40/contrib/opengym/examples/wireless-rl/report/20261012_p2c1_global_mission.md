# P2C.1 全局任务规划接手记录

2026-10-12。本轮从维护恢复后的 `e4041b5` 出发，恢复基线的运行实现为 `b32c891`。旧长会话继续暂停；其证据见 [54 小时复盘](20261012_p2c1_long_session_retrospective.md)。本文件集中记录新方案和整任务结果，详细命令、失败及验证输出在 `../log.md` 和 ROS `log/p2c1_global_20261012/`，不为每个组件另建报告。

## 判断与改变

上一轮证明了不少几何、源码和组件性质，却反复以单格失败驱动局部规则，最终没有同一冻结的完整矩阵。探索、补能、让行和集合各自管理 pending/handle、偏好和超时，互相叠加后难以判断整个舰队在等待什么。把计算放在串行状态回调里，也会让本已交付的输入在计算及证据编码期间过期。

本轮采用一个规划器和一个执行器：

- 单工作线程读取不可变地图及复制的网关交付状态，输出几何提案。仅允许一个在途计算，没有陈旧提案队列。工作线程不发 ROS 指令、不改变任务状态。
- 在有界候选池中比较机器人组合，按未知地图和未观察相机区域的合并信息扣除重复覆盖，避免仅按单机首选顺序贪心。实际探索目标是一个完整观察航段，其整段距离、终点返航和当前位置返航分别定价；没有把未执行的长前沿当作实际导航距离。
- 集合采用全机永久终点，考虑完整去程、返充、队友等待与原 5 秒保持。临时让行目标不覆盖永久集合终点；地图使永久计划失格时，待已有动作和返航闭合后重新考虑整个集合。
- 补能、清道和集合是一组依赖关系。无真实返航尚在执行时，电量不足的清道者可以先走其自身完整、净空且已付得起的返充路线；随后恢复被阻挡的请求。未知返航路保持暂停。
- 全部中央导航角色共用每机器人一个 generation 所有者。取消 pending/accepted 动作只提出取消，直到相匹配的真实 result Future 闭合才释放。旧结果不能释放新动作；让行、信息勘察、扫描不获得普通探索计数。
- 执行器只从当前已交付数据重建路、身体遮挡、1.8m 实际航段预约和完整预算。预算仍使用原 1.25 去程包络、返航偏离/等待/反应/安全余量模型。旧源时间戳不续租；编码后、实际发送前和迟到接受后再次检查。

原 `HeadquartersControl` 的输入适配、网关和几何算法保留，独立派发循环在 global 模式关闭。baseline 模式保留供声明过的算法比较，不把两种模式结果混算。全局规划是有界组合搜索，不声称求出连续空间的全局最优解。

## 取回的有效工作与修复

保留恢复前已有的完整路径安全预算、原生本地返航优先、能量记账和 Future 串行化。另选择性取回上一轮有原扫描支持的自体回波修复：只修改 SLAM 内部映射副本，身体框取现有 SDF/URDF 的交集；边界噪声须有严格框内种子和至少三个连续射线，带宽为现有噪声 3σ 加半个量程分辨率。原始 scan、Nav2 与世界/机器人模型不变，不能外推为硬件识别保证。

取回只读完整 CDR 旁录、完整应用图与完整原生电池发布留存。新增网关实际交付源旁录，明确声明新增只读订阅；这些数据只进入评估，不成为中央隐蔽输入或新增应用无线流。独立读者核验原地图内容、姿态/TF、电池及检测，重算标量预算，检查所有权代次与预约；失去原件必须失败。

接手检查已修复派发证据编码期间过期仍继续发指令的问题，以及派发端路径缓存跨地图/机体位置复用的问题。缓存只复用完全相同的几何和身体位置，不复用预算、能量或源租约。

## 验证边界与验收顺序

实际构造节点、真实 DDS 和真实 ActionServer/Futures 测试已覆盖自动提案、真实接受/结果、取消闭合和原件绑定。其服务端只模拟动作生命周期，没有 Gazebo、Nav2 物理导航或真实补能，零原生任务信用。夹具丢样本、错误主题和旧夹具缺 TTL 等失败均留存；修正夹具不能替代整任务验证。

验证完成：1,597 项功能检查 PASS/145.87s（原两个全仓风格 lint 入口不计功能验收）；四包构建 PASS/55.5s；190 保护文件、6 原有授权变更及新规划/过滤器文件、54 静态协议格和原 native 常量/Future 契约检查 PASS。新核心模块 F821/F822/F823/E999 静态检查 PASS。新旧 manifest 的 case 对象、时长、种子、物理刺激逐字一致；共享命令、完整图和原件旁录声明一致。

接着推送单一冻结：四开发 → 15 非留出正式 + 两受控物理 → 首次两格 917 → 完整 17 正式 + 两物理门禁。所有原场景、种子、目标、电量、300s、.35m、.05m/s、.10rad/s、连续 5s、2/5/60s 源龄、物理刺激和反例保持。失败记录不回填，不跨版本凑矩阵。
