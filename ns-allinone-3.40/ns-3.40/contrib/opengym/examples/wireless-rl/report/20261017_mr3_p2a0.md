# MR3-P2A.0：训练前工程与接口准备

用户2026-10-17授权继续解决P2A，并允许增加前置准备。本步实施与原生核验进行中，
不启动新pilot、不提供P2A完成或95%可靠性信用。路线和验收边界见
[实施计划](../IMPLEMENTATION_PLAN.md)，独立问题归因见[审计](20261017_mr3_p2a0_audit.md)。

## 本步修复

1. SLAM节点拥有的LaserAssistant、MapSaver、LoopClosureAssistant和CeresSolver原先反持
   node shared_ptr，形成引用环。实际ROS节点CPU回归在旧码三轮均未析构、sensor未注销。
   改为所属节点生命周期内借用，join后台线程后按依赖销毁；active main明确reset。
   不捕获Karto异常。此缺陷已独立复现；没有V6具体throw/stack，不能称其异常根因已经证明。
2. collector失败时保存已返回决策的原张量/掩码/动作/value/logprob/reward/dt和真实终止标记。
   明确training_eligible=false，无GAE/returns、无补造尾步；未返回的原生决策仍在worker原件。
   一条环境关闭失败仍使整round禁止更新，其余关闭回执不会因首个异常而跳过。
3. 候选规则升级为`mr3-per-robot-geometric-staging-v4`：融合与合法已交付本地图前沿按世界
   坐标投影后取几何并集；只有融合图free端点可进入。旧own-map路径、.29m/.39m净空、
   K8/FPS和联合mask保持；不清除占据seed。V3/legacy旧格式继续独立精确审计。每个快照的完整四地图在既有
   encoder线程归档，绑定同次输入和现有SHA，延迟编码不会替换为后来地图；audit_path空时不写。
4. peer失败保留实际使用的机器人对、中心距、门槛、odom/TF/源时间和速度；非有限辅助
   分量编码null不阻断失败发布。评价器仅在本地报告保存最新ModelStates接收缓存，明确
   无source stamp，不能当作与安全触发严格同刻的真值。策略/奖励/成功门禁不变。

## 预声明原生工程矩阵

见[机器预声明](assets/20261017_mr3_p2a0/predeclared_plan_v1.json)。
仅新提交推送且干净的同一冻结运行，run-id唯一。全部真实Gazebo、每环境三机器人，
无GPU、无optimizer、无policy训练；脚本只为工程接口/安全检查，不构成探索baseline或RL。

| 阶段 | 工作量 | 目的 |
| --- | --- | --- |
| terminal | 1worker，open101两episode，各4API上限，显式terminal-probe | 保留短终态与零尾/评价器ACK门禁 |
| reset | 2workers，每worker两次open101，各16步上限 | 新候选原生接口、重复完整重建和并发关闭 |
| deadline | 1worker，open101，300步KEEP，deadline-probe | 长任务截止、严格终态关闭和实际SLAM析构 |

总上限372API/371次真实脚本决策，预热/关闭时间单列。任一阶段工程审计失败立即停止后续阶段，
不自动重试，不将task安全失败当infra无效；严格失败原件保留后再诊断。每次native/scalar/
contact/clock/command/phase审计通过才开始下一阶段。命令维护于
[ROS启动页](../../../../../../../ros2_ws/ros2-multi-robot-automap/launch_commands.md)，
独立入口`python -m mr3_learning.audit_preparation`重用已冻结W7门禁并绑定本次新源码。

本矩阵属于P2A.0工程成本，另列账，不占用/扩展原累计pilot；原pilot仍为已用
2226决策/11494.045260453597墙秒、剩1870/2905.954739546403，无新pilot或开发验证调用。

## 尚未闭合与下一门禁

原末期独立物理位置缓存的两台中心距也小于.5m，但与触发输入缺精确时间匹配；零接触不能
反证圆包络侵入。终点mask不保证途中不冲突，当前工程probe也不提供协同安全保证。
actor没有累计参与状态：16点历史仅约3秒，progress_m在协议中一直缺失；终态奖罚依全部
成功门禁，γ=λ=1后目标一致，参与的信用仍稀疏。

用户验收P2A.0后，下一准备步须完成固定三台的静止旁路/对向/交叉安全夹具，观测实际
peer→costmap→Nav2→速度反应链，并加入可重置、仅已交付估计信息的累计参与观测；
这些步骤验收后才制定同一冻结的训练/验证。保留95%/300秒、质量、每台1m/目标、18路接触
与.50m门槛，不加手工探索兜底，不切算法，不开始P2B/gateway。
