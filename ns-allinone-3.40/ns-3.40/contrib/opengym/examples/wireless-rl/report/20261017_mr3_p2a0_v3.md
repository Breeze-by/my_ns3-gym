## 已修复的具体缺陷

1. 信息桥恢复received ROS odom时不再从随后广播的JSON删除`odometry`。
   新测试实际走publish_states→adapter→冻结快照；旧源码明确FAIL，修后77项PASS。
   断开逻辑交付后本地新样本不能穿透；TF校正、预热和旧epoch不能补活动距离。
2. Nav2恰好高出`.26m/s`或`1rad/s`一个binary64相邻值时规范到原上限，记录原值和规范。
   第二个相邻值及更大超界拒绝；最终实际输出仍严格满足原上限，没有宽epsilon。
3. 混合速度因peer接近方向被拒绝时，完整重验`(0,原角速度)`；只有该请求通过同一几何、
   源龄、残余移动及制动检查才保留原转向。没有选择新转向/目标；状态失效、包络不足和超界不能旁路。
   原拒绝及完整转向复验写入trace，实际topic FIFO仍绑定最终输出。
4. 轮缘限加速下中心速度未必每瞬间减速`.5m/s²`。独立有限轮模型给出最坏停止`.6157s`，
   加`.16s`反应后`.7757s`；增加显式`.02s`耦合余量，几何时域为`.78s`，
   每台累计停止距离预算`.144m`，同时保留原`.02m`几何余量。该模型不是原生物理响应证明。
5. 活动审计分别报告integrity和availability；普通移动探针还必须有连续可用的原始received-odom、
   非空累计量大于`.05m`、至少两个源样本，以及冻结前实际owned native send→delivered accept。
   终态注入可核验缺失状态完整性，但不得因此获得参与观测可用信用。

导航合成v1、候选v5、快照v3/张量v2/71列、七图与六路master costmap保存、20ms输出回读ACK均延续v2。
安全仍依赖有限速度、源龄、响应和制动界，不保证任意定位跳变/无界迟到或所有目标可执行。
