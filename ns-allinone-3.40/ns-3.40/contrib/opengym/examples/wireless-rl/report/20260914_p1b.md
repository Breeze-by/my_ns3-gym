# ROS 2 P1B 真值任务评估器报告

日期：2026-09-14

## 1. 目的和边界

P1B 为现有 Gazebo/SLAM/Nav2/frontier 链路增加独立只读评估器。它必须从 Gazebo 和 world
获取真值，只评估、不控制；超时样本必须输出，不能只保留成功运行。

本阶段不定义“探索完成”，不增加目标、电池、网络或 RL。因此所有定时 smoke 都记录
`task_phase=EXPLORE`、`success=false`、`termination_reason=timeout`。这不是任务失败率
结论，而是验证 episode 失败记录链路已经存在。

## 2. 实现

- `my_world.world` 加载 `gazebo_ros_state`，在 `/gazebo/model_states` 发布 evaluator-only
  真值位姿；headquarters 和 Nav2 不订阅该 topic；
- TurtleBot3 base collision 增加 contact sensor，发布 `/tbN/collision`；
- `task_evaluator` 从 SDF `<state>` 和静态 box collision 生成 0.05 m 二维真值栅格；
- 评估器记录真值路径、0.1 m 搜索访问 mask、重复探索、合并地图覆盖/准确率、Nav2
  action 结果、碰撞事件/持续时间、任务阶段和终止原因；
- 每个 episode 同时输出一份嵌套 JSON 和一行扁平 CSV；
- smoke 工具可启动评估器、等待并校验必要字段。

当前真值栅格为 261×218，原点约为 (-5.8, -5.6)，包含 25 个 lidar 高度相交的静态
box collision。world 还有一个位于实验室外部的 SUV mesh collision 未栅格化；每个结果
以 `truth_unsupported_collision_count=1` 明示该限制。

## 3. 测试和失败记录

结果：两个包构建成功。

`log/smoke/robots1_seed11_20260914-195452.log`。

修正为 `input_subscriptions` 后，又让 smoke 在等待文件时检测 evaluator 是否提前退出。

## 4. 通过结果

### 1 机器人，seed 12，10 秒

```bash
python3 scripts/ros_smoke_test.py \
  --robot-count 1 --gazebo-seed 12 \
  --startup-timeout 180 --shutdown-timeout 45 \
  --evaluation-duration 10 --evaluation-wait-timeout 180
```

结果：PASS。关键输出：10.0 秒仿真时间、3 条合并地图、122 条 model state、236 条碰撞
监测消息、0.668 m 路径、0 次 teleport、1 个成功 Nav2 goal、10.9% 正确自由空间覆盖。
JSON：`log/evaluation/smoke_robots1_seed12_20260914-195943.json`。

### 2 机器人，seed 13，10 秒

```bash
python3 scripts/ros_smoke_test.py \
  --robot-count 2 --gazebo-seed 13 \
  --startup-timeout 240 --shutdown-timeout 60 \
  --evaluation-duration 10 --evaluation-wait-timeout 240
```

结果：PASS。关键输出：10.3 秒仿真时间、5 条合并地图、172 条 model state、两台机器人
分别收到 340/275 条碰撞监测消息、1.089 m 总路径、0 次 teleport、16.4% 正确自由空间
覆盖、0 次碰撞；短窗口内两个 Nav2 goal 尚未完成。JSON：
`log/evaluation/smoke_robots2_seed13_20260914-200108.json`。

最终字段扩充后使用 1 机器人、seed 14、5 秒再次通过，验证 CSV/JSON 包含真值和合并地图
原点、分辨率、尺寸及 episode 开始/结束仿真时间。JSON：
`log/evaluation/smoke_robots1_seed14_20260914-200531.json`。

## 5. 结论

P1B 退出条件已满足并等待用户验收：固定短 episode 会产生字段完整、可判定的 CSV/JSON，
评估器不进入控制路径，真值位置不提供给 headquarters/Nav2。

下一步 P1C 需要先固定正式实验的 world、共同出生/充电区域、探索完成阈值和最大 episode
时长，再运行多个独立 seeds 的 2 机器人 ideal/unlimited-communication 基线。
