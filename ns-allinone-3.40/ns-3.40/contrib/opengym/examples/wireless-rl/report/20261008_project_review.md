### 6.2 控制成本和观测可部署性

ideal总发送CDR平均约213–373kbit/s；delay_rooms3约546kbit/s；原全矩阵最高一秒约664.51kbit/s。新增candidate/request/grant/heartbeat占ideal总代价32.44–38.44%；加critical/ACK等非data占43.13–51.81%；延迟格新增协议比例约49.80–53.69%。具体逐格/逐角色数值在机读证据，payload和envelope CDR不能混用。

所以“省下地图payload”不是充分目标：如果候选逐个握手、心跳/反馈继续消耗，总代价可能不降。当前每候选立即发candidate/request，未授权至少.75秒重发、最多三组，不是所有候选共享4Hz限制。控制组重试、应用可靠消息重试、MAC重传是三层，P4必须分别计数。

AP只看已交付candidate/request/heartbeat与history，远端current_queue为null；心跳pending_count是带年龄的旧快照。当前always-grant只有测量功能，不是已实现的优化策略；AP本机下行消息直接本地准入，不虚构发给自己的一轮控制流。逻辑机器人/AP actors在同一gateway进程，代码路径实现可见性，不构成真实分布式进程隔离；P4/P8部署还须证实跨端wire契约和同一观测边界。

### 6.3 容量、时延和“负结果”

当前应用替身按配置注入delay/loss等结果，没有PHY速率、MAC服务、竞争/序列化或功率模型；attempt可以同一时刻发送任意大小消息。因此容量瓶颈是**未测量、不可识别**。有限应用队列overflow或源TTL到期真实可测，但不能当作802.11拥塞。旧报告“应用模型无容量瓶颈负结果”的说法在本次当前计划中纠正，原日期报告原文保留并由本评审限定。

实际airtime/J正确保持null。`8*envelope_cdr_bytes/1e6`仅为按假定Mbps/瓦数换算的条件系数，不含IP/UDP/DDS/MAC/PHY开销、接收/空闲/侦听/聚合和真实重传；条件成本不是无线校准。任务电池单位也不是J，当前c_tx=0。不能把较低应用bit/s与某理论PHY速率相除就宣称“链路有富余”或“协议无必要”。

## 7. 后续目标、路线与指标

### 7.1 最终目标保留，投资顺序调整

继续保留固定消息语义、固定任务栈、中央部分可观测准入、2/3机器人仿真和至少2机器人实物任务；不默认升级成MARL，不同时改视觉、规划、MAC/MCS和编码。P6学习是条件分支；无RL也完成统计、实物与限制报告。

修订后路线为：安全补强/新任务冻结；P4A-0包契约 → P4B-0原负载被动Wi-Fi测量/早期网卡标定 → P4A-1因果闭环 → P4B-1独立标定验证 → P5强方法/GO判断 → 条件P6 → 两分支均完成P7/P8。离线包契约/被动测量可以先行，安全门阻断的是新的闭环任务比较。

这样先解决“实际网络能否形成值得研究的总代价—任务取舍”，再投入昂贵ROS/Gazebo时钟桥。被动trace可验证服务时间/排队/重传/干扰，不能证明不同准入策略的任务收益；闭环不能省略。背景流必须有实测/真实应用依据，不用虚构高频图像或压低无依据网络预算制造学习优势。

### 7.2 P4的几个不可省略的接口

| 接口 | 验收要求 | 常见错误 |
|---|---|---|
| payload/packet | 不可变实际字节/内容hash；MTU、消息/fragment身份；完整重组后才交付；源TTL不刷新；各层字节闭合 | 网络送空包，接收时再读ROS对象的最新值；丢一个fragment仍交付完整地图 |
| replay/重试 | 固定canonical输入、独立RNG streams和seed逐事件一致；声明是生成/准入trace还是已发送attempt trace | 旧attempt已经含重试，新协议又重试；把固定旧轨迹当可反事实的任务环境 |
| 时间桥接 | 固定Δ/因果窗口/量化边界、message/clock ACK和背压；故障退出；wall-time超时单列 | 网络提前收到未来位姿/消息；clock推进未确认；把CPU迟到误算网络delay |
| PHY/MAC | AP+2/3 STA802.11n；参数来源、MAC队列/重传/忙时与实际发送区间 | 继续用toy队列服务率替代Wi-Fi；把每个MPDU回调重复累加聚合帧airtime |
| 执行观测 | AP本地队列可见；STA当前队列不可见；RSSI/MAC反馈需真实采样/交付年龄/上报成本 | 把离线全局MAC counter免费塞入actor，或把heartbeat旧深度当即时值 |
| 候选价值 | 当前candidate只有元信息，不含未交付地图的新信息量；task-value须基于已交付摘要/AP旧图预测，新增gain需付费扩展和新冻结 | 先读被拒绝地图/真值再决定准入；将evaluator正确覆盖率当部署观测 |
| 性能预算 | 记录episode-start/end的wall与sim时间、实际RTF和CPU/RAM峰值，分开启动/任务/导出；重复测量后确定训练预算 | 用整个launch起止含收尾的wall时间替代任务RTF；只记CPU亲和性就称资源测量完成 |
| calibration | 拟合位置与验证位置/条件分开；网络分布误差和任务差异分报 | 无实测却写sim-to-real；用同一位置拟合又验证 |

本地ns-3 3.40文档支持Wi-Fi-only情形先用YansWifiPhy；需要频率相关或混合技术干扰时再选SpectrumWifiPhy。RealTime best-effort只能尝试追赶wall clock，不自动解决因果性/确定性。参考[3.40 Wi-Fi源文档](https://gitlab.com/nsnam/ns-3-dev/-/blob/ns-3.40/src/wifi/doc/source/wifi-design.rst)与[3.40 realtime源文档](https://gitlab.com/nsnam/ns-3-dev/-/blob/ns-3.40/doc/manual/source/realtime.rst)；本次以仓库对应版本的本地内容为准，避免套用新版API。

### 7.3 主指标与失败处理

主假设改为“在完整成功率、失败惩罚完成时间和安全不劣约束下，降低总网络成本”。成功/时间非劣界、安全风险允许范围、一个主成本单位和样本精度必须预注册，本次不在看过历史数据后随意给出能保证PASS的数值。

- P3阶段total attempted envelope CDR可作代理；它包含真实控制/应用重试，仍不是wire airtime。
- P4默认候选成本A_tx为全网radio真实TX区间之和，包含控制/前导码/重传；并发可使总和大于任务时长。另报固定观察点TX/RX/CCA_BUSY区间并集的busy比例，不能混成同一个airtime。
- 硬件无法可靠测A_tx时，正式比较前选择可测的总wire bytes并限定主张；radio J须实测或标定TX/RX/idle功耗，不能用RF发射功率替代网卡总耗能。
- H=300的时间分析：成功取min(T_COMPLETE,H)，FAILED/PARTIAL/timeout均取H。早期FAILED是吸收结局，不能在失败时按独立右删失。若用生存表达，应基于成功累计发生概率，而不是删掉失败者后拟合成功时间。
- 通信只统计真实暴露时间，不为早期失败补H的虚构流量；先过成功/时间/安全约束，低成本但快速失败的策略不能判优。总代价、真实持续时间成本率、阶段成本、受保护通信成本同时报告。

TDI继续保留为历史定义的退化摘要，但不是唯一主终点；它对完整成功后的时间退化取0，因此不能掩盖更慢的COMPLETE。完成时间、AoI、时延与cost曲线需同时展示。

### 7.4 统计与GO/NO-GO

20/24个held-out元组只是场景覆盖下限。即便24/24都成功，独立同分布模型下95% Wilson成功率下界也只有约86.20%；无法凭这个样本量证明很高可靠性。14次零事故时，独立同分布模型下单侧95%事故概率上界约19.26%。这些是样本精度的数学例子，**不是**给当前非随机固定矩阵计算总体置信区间。

未来按world/目标/能量/干扰冻结新train/validation/held-out；策略配对同元组，运行顺序预先随机/平衡，固定CPU/RMW/reset规则，重复运行嵌套在元组中，共用ideal不重复计独立样本。样本量根据冻结的非劣界/配对相关性/精度预估，不能挑seed。目标/出生点还应让tb2/tb3成为发现者，避免只测同一发送者。

P5先做task-value greedy、freshness/deadline、link-aware与event/periodic强方法。在同观测/同协议/同物理参数下，确认有可执行动作和可测长时取舍；如果启发式足够，结论就是无需复杂学习。SchedNet原工作包含学习式调度/编码/任务行为，本项目固定内容/任务的比较只能称SchedNet-inspired适配，并声明是否学习；不能误称原论文复现或把学习版本写作非学习基线。原文入口：[Learning to Schedule Communication in Multi-agent Reinforcement Learning](https://arxiv.org/abs/1902.01554)。

允许P6的条件是计量/安全/观测闭合且存在强贪心难以处理的可解释时序场景；训练后优于最强baseline依然是结果，不是必须调参达到的工程退出条件。NO-GO时继续非学习节流或无线负结果分析、P7和双机实物验证，最低项目目标仍有完整交付。

动作必须有实际候选：当前普通上行仅map/pose/TF，AP下行融合地图尚为直接本地准入；确认检测、电池、导航是受保护路径。不能把概念中的“检测证据/任务命令”硬做成不存在或可越过安全的DQN动作。非劣须靠预声明δ和正确方向的差值置信界支持，p>0.05或“均值差不显著”都不证明非劣。
